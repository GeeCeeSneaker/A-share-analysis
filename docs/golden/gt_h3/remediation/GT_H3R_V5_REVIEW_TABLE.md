## 使用方法

1. 打开每行的官方材料，阅读官方原文，不使用搜索摘要、接口输出或 AI 总结代替原文。
2. 对照“必须核对”列检查代码、日期、事件、适用板块/规则和期望值。
3. 全部一致填 `APPROVE`；任一不一致、链接失效或原文不证明该事实，填 `REJECT` 并写一句原因。
4. 12 行完成后，真实 Owner/Human Reviewer 需在 PR 评论明确 12/12 结论、113 条沿用确认、
   `50` 已被中和或有明确含义，并给出 human marker。
